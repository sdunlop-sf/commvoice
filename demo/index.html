Connect the assistant

This demo runs the AI directly in your browser using Google Gemini. Paste a free Gemini API key to enable real conversation. Your key is stored only in this browser (nothing is sent to this website or saved in the code). Get a free key at aistudio.google.com/apikey.

Optional: natural voice with ElevenLabs

Without this, answers are read by your browser's built-in voice. Add an ElevenLabs API key for a natural, human-sounding voice you can choose. The key is stored only in this browser. Get one at elevenlabs.io.
